# 🤖 A AI - Sentiment & Text Classifier

An interactive, web-based Natural Language Processing (NLP) application built as part of the **IBM BOB ** hands-on activity for the **Machine Learning & Applied AI Internship**.

---

## 📌 Project Overview

This project demonstrates a real-time **Applied AI & Text Classification System**. It takes user text input (such as product reviews, feedback, or comments), performs tokenization and keyword extraction, and classifies the sentiment into **Positive**, **Negative**, or **Neutral** alongside a calculated **Confidence Score (%)**.

---

## 🚀 Key Features

- **Real-Time Sentiment Analysis:** Instantly analyzes user input and renders confidence metrics.
- **Rule-Based ML Classifier Logic:** Simulates core NLP feature extraction and sentiment scoring.
- **Dynamic Status Badges:** Visual feedback using status colors (Green for Positive, Red for Negative, Yellow for Neutral).
- **Responsive Dark UI:** Designed using modern UI standards optimized for modern browsers and mobile interfaces.

---

## 🛠️ Tech Stack

- **Platform:** IBM BOB (Build on BOB) IDE
- **Front-End:** HTML5, CSS3 (Flexbox, CSS Variables, Modern Layouts)
- **Logic / AI Core:** JavaScript (Rule-Based NLP & Sentiment Engine)
